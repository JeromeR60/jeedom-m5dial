Installer un M5Dial pour Jeedom

Firmware du plugin Jeedom M5Dial, à installer depuis ce navigateur, sans logiciel.

  1. Utilisez Chrome ou Edge sur un ordinateur (Windows, macOS ou Linux).
  2. Branchez le M5Dial avec un câble USB-C de données (certains câbles ne font que la charge).
  3. Cliquez sur Installer, choisissez le port du M5Dial dans la liste, puis acceptez l'effacement.
  4. Attendez la fin (environ 1 à 2 minutes). Le bouton redémarre sur son portail de configuration : suivez la documentation du plugin (portail Wi-Fi puis appairage).
Votre navigateur ne permet pas l'installation : utilisez Chrome ou Edge sur ordinateur. L'installation demande une page sécurisée (https).

Le bouton n'apparaît pas dans la liste ? Essayez un autre câble USB-C. Si besoin, débranchez le M5Dial, maintenez le bouton situé à l'arrière, rebranchez-le, puis relâchez.

L'installation efface entièrement le M5Dial (Wi-Fi et appairage compris). Pour mettre à jour un bouton déjà installé, utilisez plutôt Jeedom : plugin M5Dial, « Mettre à jour le firmware ».
